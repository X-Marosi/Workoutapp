## Features

- **Workout Tracking**: Record sets, reps, weights, and RPE for each exercise
- **Training Plan Management**: Create, save, edit, and reuse workout plans
- **Smart Plan Generator**: Generate personalized workout plans based on your goals, available equipment, and targeted muscle groups
- **Exercise Library**: Browse and search through a comprehensive database of exercises with detailed descriptions and images
- **Progress Tracking**: Monitor your progress with weight tracking charts and workout calendar
- **Offline Support**: Full functionality even without internet connection
- **User Authentication**: Secure login and registration system

## Technologies Used

- **React Native**: Cross-platform mobile application framework
- **Expo**: Simplified React Native development environment
- **TypeScript**: Type-safe JavaScript superset
- **Firebase Firestore**: Cloud NoSQL database for data storage
- **Firebase Authentication**: User authentication service
- **Expo Router**: File-based routing system
- **React Native Charts**: Visual data representation

## Installation

### Prerequisites
- Node.js (v12 or higher)
- npm (v4 or higher)
- Expo CLI

### Setup Instructions

1. Clone the repository:
  ```bash
  git clone https://github.com/yourusername/workout-tracker-app.git
  cd workout-tracker-app
   ```
2. Install dependencies:
  ```bash
   npm install
   ```
3. Run the application:
  ```bash
   npx expo start
   or
   npx expo run:android
   ```
Or
```bash
  Try it out using a Virtual Device
```
